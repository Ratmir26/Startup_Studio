# 🧠 Валидатор идей

**Проверь свою идею за пару минут и пойми — стоит ли её развивать.**

Инструмент для быстрой валидации гипотез через аргументы, а не эмоции.
Помогает увидеть слабые места идеи до того, как ты потратишь время и ресурсы.

---

## 🚀 Почему это важно

Люди часто влюбляются в идеи и начинают их реализовывать без проверки.
В итоге — потерянное время, энергия и разочарование.

**Валидатор идей решает это:**

* заставляет формулировать аргументы
* балансирует «за» и «против»
* даёт простой и быстрый вердикт

---

## ⚡ Как это работает

1. Вводишь свою идею
2. Добавляешь аргументы **ЗА** и **ПРОТИВ**
3. Получаешь автоматический вердикт

👉 Всё занимает несколько минут и не требует регистрации

---

## 📊 Пример

**Идея:** Онлайн-школа с гибким расписанием

**ЗА:**

* Удобно для учеников
* Можно учиться в своём темпе

**ПРОТИВ:**

* Сложно контролировать дисциплину
* Родители могут быть против

👉 **Вердикт:** ⚖️ Нужно больше данных

---

## 🧠 Логика валидации

```text
pro = количество аргументов ЗА
con = количество аргументов ПРОТИВ
score = pro - con
total = pro + con
```

Правила:

* Если `total < 3` → 🟡 Нужно больше данных
* Если `pro > con × 1.5` → 🟢 Идея перспективная
* Если `con > pro × 1.5` → 🔴 Идея слабая
* Иначе → ⚖️ промежуточная оценка

### Почему коэффициент 1.5?

Он задаёт «запас прочности».
Если аргументы ЗА лишь немного перевешивают — это может быть случайность.
Идея считается сильной только при заметном перевесе.

## 🆚 Чем это отличается от заметок

| Обычные заметки | Валидатор идей     |
| --------------- | ------------------ |
| Просто текст    | Структура мышления |
| Нет анализа     | Есть вердикт       |
| Хаос мыслей     | Баланс ЗА/ПРОТИВ   |
| Нет вывода      | Чёткий результат   |

---

## ⚠️ Ограничения

* Это не математическая модель и не даёт точных прогнозов
* Качество результата зависит от качества аргументов
* Нет backend — данные хранятся только в браузере
* Нет синхронизации между устройствами
* Один HTML-файл — не масштабируется как полноценное приложение

---

## ❌ Кому не подойдёт

* Тем, кто ищет точные расчёты или аналитику
* Тем, кто не хочет формулировать аргументы
* Для сложных научных или финансовых решений
