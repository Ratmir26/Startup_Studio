## 📄 CONTRIBUTING.md

# 🤝 Как внести вклад

Спасибо, что решили помочь проекту! Вот как это сделать.

## 📋 Правила

1. **Один PR — одна фича/фикс**
2. **Пиши тесты** для новой функциональности
3. **Следуй стилю кода** (ESLint + Prettier)
4. **Обновляй документацию** при изменениях API

## 🚀 Быстрый старт

# 1. Форкни репозиторий
# 2. Клонируй
git clone https://github.com/YOUR_USERNAME/idea-validator.git
cd idea-validator

# 3. Установи зависимости
cd frontend && npm install
cd ../backend && npm install

# 4. Запусти
# Терминал 1 - Бекенд
cd backend && npm run dev

# Терминал 2 - Фронтенд
cd frontend && npm run dev

## 🧪 Тестирование

## Тесты
npm run test

# Frontend тесты
cd frontend && npm test

# Backend тесты
cd backend && npm test

# E2E тесты
npm run test:e2e

Создай ветку: feature/имя-фичи или fix/описание-бага

Сделай коммиты с понятными сообщениями

Открой Pull Request в main
